# Cursos ITS

Landing page del Área de Informática del Instituto Tecnológico Superior Arias Balparda.

El sitio está construido únicamente con HTML, CSS y JavaScript, sin frameworks ni dependencias externas.

## Estructura

- `site/index.html`: contenido de la página.
- `site/styles.css`: diseño, adaptación móvil y animaciones.
- `site/script.js`: modales de cursos y navegación móvil.
- `site/assets/`: logo, favicon e imagen para redes sociales.

Los cambios enviados a la rama `main` se publican automáticamente en [cursosits.github.io](https://cursosits.github.io/).
